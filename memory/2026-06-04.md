### Critical Fix: DMX Engine Flush
**File:** `apps/web/src/lib/dmxEngine.ts`

- **Problem:** `prevMap.get(channel) !== value` comparison blocked re-sending identical DMX values. After the first send, the buffer would never resend the same value, even when the beam needed it (e.g., after a disconnect/reconnect or when a new client connected).
- **Fix:** Added `forceNext` Map that tracks channels that must be force-sent on next flush, regardless of comparison. `setChannel()` now automatically marks the channel for forced send. On socket reconnect, `forceAll()` clears the prev cache and marks all channels.
- **New methods:**
  - `forceAll()` — Clears prev cache and marks all channels for forced resend (called on socket reconnect)
  - `flash(universe, channel, value, durationMs)` — Sends a brief flash to a channel then reverts to previous value
  - `blackout(universe, startAddr, numChannels)` — Zeros all channels for a fixture
  - `fullOn(universe, startAddr, channels)` — Sets dimmer/color to 255, pan/tilt to 127, strobe to 0
  - `isRunning()` — Returns whether the flush loop is active
- **Also:** Flush now checks `socket.connected` before emitting to prevent silent failures
